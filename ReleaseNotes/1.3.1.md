# MeetingNotes 1.3.1（26）

> 免费自签名正式版，未经 Apple Developer ID 签名或公证。首次安装可能需要在 macOS 中手动允许；请仅从 NakuTop/MeetingNotes 官方 GitHub 下载。支持 Apple Silicon Mac，macOS 15 或更新版本。

- 在线会议改用纯系统音频捕获，不再持续采集桌面画面；修复系统音频状态、缓冲及诊断提示。
- 截图支持直接点选目标窗口，Esc 取消；修复选窗高亮、点击与截图生成问题，保持无损 PNG 清晰度。
- 优化长会议转录刷新、文字编辑与自动保存，修复录制期间实时转录显示。
- 重点总结与完整纪要切换支持更大的点击区域，保留原有磨砂透明界面。
- 手动文字编辑支持原生 ⌘Z 撤销与 ⇧⌘Z 重做，修复撤销结果与自动保存同步、清空文字后的恢复。
- FluidAudio 更新至固定版本 0.13.2。高精度模型、均衡模型、Notion 手动替换同步与 DeepSeek 数据边界保持不变。

本轮 Beta 功能已由用户实机确认。发布验证仅使用后台测试；不运行干扰桌面操作的 UI 自动化。
