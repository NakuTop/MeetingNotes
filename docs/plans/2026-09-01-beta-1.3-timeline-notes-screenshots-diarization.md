# MeetingNotes Beta 1.3 Timeline Notes, Screenshots, and Diarization Implementation Plan

> **Execution:** REQUIRED SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add timestamped meeting notes and local screenshots to the existing recording timeline, include notes in generated documents, upload screenshots only to Notion, and set the verified FluidAudio clustering threshold without changing stable MeetingNotes behavior.

**Architecture:** Add two SwiftData child records owned by `MeetingRecord`, store screenshot originals inside the existing per-meeting directory, and expose one `@MainActor` recording-annotation view model to the existing floating panel. Build DeepSeek inputs from text notes only, while a separate Notion preparation path creates temporary JPEG derivatives, uploads all images before page mutation, and then reuses the existing checkpointed replacement transaction.

**Tech Stack:** Swift 6, SwiftUI, AppKit, SwiftData, ScreenCaptureKit, ImageIO, FluidAudio 0.12.6, Notion REST API, XCTest, XCUITest, xcodebuild.
