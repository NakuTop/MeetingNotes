# 转录、说话人分离与双模式纪要验收指南

更新日期：2026-08-02  
测试对象：`~/Applications/MeetingNotes 测试版.app`

适用平台：Apple Silicon、macOS 15 或更高版本

## 验收前准备

- 使用测试版完成验收，不要替换或启动 `/Applications/MeetingNotes.app`。
- 确认麦克风、屏幕与系统音频录制权限已授予 MeetingNotes；在线会议还需实际播放一段远端声音。
- 准备一段短中文语音、先前约 28 分钟且说话人分离失败的线下会议、以及可代表约两小时会议的长转录。
- 若要验收自动归档，请先在设置中保存可用的 Notion Token 与父页面链接。
- 每一步都记录结果；出现失败时保留界面提示和操作顺序，但不要复制 API Key、Token、完整转录或音频内容到日志。

## 九步人工验收

1. **确认平衡模式仍为默认并可用。** 首次打开设置，确认转录质量显示“平衡”；用现有模型转录短中文语音。预期：不必重新下载既有模型即可完成，文字正常显示；如果先前保存过质量偏好，则先切回“平衡”并保存后再验证默认模型本身。

2. **下载并切换高精度模型。** 在设置中选择“高精度”，完成首次下载后保存，再转录同一段短中文语音。预期：新会议使用高精度模型完成转录；下载或准备期间有明确状态，失败时可重试，且已保存的旧会议不受影响。

3. **重试约 28 分钟的旧线下会议。** 打开先前说话人分离失败但已有最终转录的会议，执行“重试说话人分离”。预期：直接复用已保存录音与转录时间轴，不重新运行转录；成功后显示“说话人 N”，失败时原转录仍完整保留，也不会生成总结或纪要。

4. **验证在线会议身份分轨。** 新建在线会议，同时对本机麦克风说话并播放至少两位远端人员的声音，结束后等待处理完成。预期：本机麦克风内容始终标记为“我”；系统音频中的远端人员显示为可区分的“远端 N”，且混合录音仍可播放。

5. **用双位置滑块分别生成两种文档。** 在同一会议中先把滑块置于“重点总结”并生成，再切到“完整纪要”并生成。预期：滑块切换顺畅且可反复选择；两种内容分别保存并可来回查看，生成第二种不会覆盖第一种，完整转录也仍可展开查看。

6. **确认两小时完整纪要经过提炼。** 对约两小时会议生成“完整纪要”。预期：保留议题脉络、关键事实、决定、行动项与待确认问题，但明显短于逐字转录，不是一字不差复述；重要内容不因提炼而丢失。

7. **开启 Notion 后只自动归档当前类型。** 打开“生成后自动归档到 Notion”，先选择并生成“重点总结”，再选择并生成“完整纪要”。预期：每次都先在本地保存成功，再仅归档当次滑块选中的文档；第二次不会把另一种文档混入或覆盖。重新生成某一种时，只替换该类型对应的 Notion 内容，旧内容应在新内容成功持久化后才被移除。

8. **关闭 Notion 后两种内容仅保存在本机。** 关闭“生成后自动归档到 Notion”，分别重新生成“重点总结”和“完整纪要”。预期：两种本地内容都更新且仍可切换查看；界面不进入归档阶段、不新增 Notion 页面或区块，也不发起 Notion 请求。

9. **重启后确认设置和内容持久化。** 完全退出再重新打开测试版，回到同一会议。预期：转录质量选择、Notion 自动归档开关、重点总结、完整纪要及其各自归档状态均保持；两种内容仍能通过滑块查看，旧会议仍可读取。
